# 반려동물 동반 여행 인프라 대시보드 (pet_travel_infr)

반려동물 동반 숙소를 기준으로 주변 병원·약국·카페·식당·여행지가 충분한지 평가하고,
**여행 상품을 만들기 좋은 지역**과 **제휴 숙소를 발굴할 지역**을 찾는 기획자용 대시보드입니다.

- 사용자: 반려동물 여행 상품·제휴를 기획하는 기획자
- 결과물: `index.html` (파일 하나로 동작, 서버·설치 불필요)


## 여는 방법

1. `index.html`을 크롬·엣지 같은 브라우저에서 엽니다(더블클릭). 인터넷 연결은 필요 없습니다.
2. 앱·에디터의 **파일 미리보기에서는 스크립트가 막혀 눌러도 반응이 없을 수 있습니다.** 반드시 브라우저로 여세요.
3. GitHub에 올렸다면 GitHub 화면에서는 코드만 보입니다. 화면으로 보려면 GitHub Pages를 켜고 파일명을 `index.html`로 바꾸거나, 파일을 내려받아 브라우저로 여세요.
4. CSV 내려받기 버튼은 브라우저에서 파일로 저장되고, 링크(Artifact) 버전에서는 클립보드로 복사됩니다.

## 화면 구성

| 탭 | 답하는 질문 | 주요 내용 |
|---|---|---|
| ① 상품 후보 지역 | 어느 지역이 여행 상품을 만들기 좋은가 | TOP 3, 상위 15개 지역의 **순위 + 인프라 등급** 차트, 선택 지역 상세 |
| ② 제휴 기회 | 인프라는 충분한데 동반 숙소가 적은 곳은 어디인가 | 제휴 기회 지역 막대, 시도별 숙소 수·등급 분포, 시군구 리스트(정렬·검색·CSV) |
| ③ 숙소 점검 | 이 숙소 주변은 괜찮은가 | 위경도 산점도 지도, 숙소 검색 목록, 반경 안 시설 수와 가까운 시설 표 |
| ④ 데이터 품질 | 이 데이터를 얼마나 믿을 수 있는가 | 시설 정보 최신성, 항목별 기재율, 분석의 한계 |

- 모든 항목 옆의 **`!` 아이콘**을 누르면 설명이 나옵니다. 헤더의 `기준: … !`에서 평가 기준 전체를 볼 수 있습니다.
- 상단의 **시도 선택**과 **평가 기준 설정**(반경 3·5·10km, 시설별 최소 개수, 카페·식당 완화, 순위 최소 동반 숙소 수)은 모든 탭에 적용됩니다.

## 평가 기준

### 인프라 등급 (숙소 1곳마다)

| 영역 | 시설 | 충족 조건 (기본값) |
|---|---|---|
| 안전 | 동물병원, 동물약국 | 반경 5km 안에 각각 1곳 이상 |
| 즐길거리 | 카페·식당, 여행지·문화시설 | 반경 5km 안에 각각 1곳 이상 |

| 등급 | 조건 | 동반 숙소 중 비율(기본값) |
|---|---|---|
| 충분 | 안전 2종 충족 + 즐길거리 2종 충족 | 38% |
| 보통 | 안전 2종 충족 + 즐길거리 1종 충족 | 34% |
| 안전만 | 안전 2종 충족 + 즐길거리 0종 | 3% |
| 의료 부족 | 병원 또는 약국 기준 미달 | 25% |

지역의 **충족률 = 동반 숙소 중 "충분" 등급의 비율**입니다.

### 다양성

숙소 반경 안에서 갈 수 있는 시설 **유형 수**(여행지, 박물관, 미술관, 문예회관, 카페, 식당 중 몇 가지, 0~6)입니다. 지역 값은 동반 숙소의 평균입니다.

### 상품 적합도 (100점)

`동반 숙소 수 40점 + 충분 비율 40점 + 다양성 20점`

- 각 항목은 **동반 숙소가 3곳 이상인 시군구끼리의 백분위**로 환산한 상대 점수입니다.
- 기본 설정에서 1위는 충북 충주시(88점), 2위 경북 경주시(86점), 3위 경남 밀양시(84점)입니다.

### 제휴 기회 지역

동반 숙소가 **2곳 이하**이고, "충분" 등급인 **제휴 후보 숙소가 10곳 이상**인 시군구입니다(기본 설정에서 85곳).
도심(서울 중구·종로구 등)은 일반 호텔이 많아 상위에 오르는 경향이 있습니다.

### 숙소 구분

- **동반 확인 숙소 (2,095곳)**: 동반 시설 데이터의 펜션·호텔, 야영장 중 반려동물 출입이 가능한 곳(`가능`, `가능(소형견)`).
- **제휴 후보 숙소 (41,778곳)**: 인허가 데이터의 영업 중인 숙소. **동반 가능 여부를 알 수 없으므로** 제휴 협의로 확인해야 합니다. 여관·여인숙·생활숙박은 제외했습니다.

### 처리 요약

1. 시설은 `(시설명, 도로명주소, 카테고리3)`로 중복 제거(70,650행 → 약 23,900곳).
2. 인허가 3종의 좌표는 Bessel 중부원점 TM(EPSG:5174)이라 위경도로 변환했습니다(서울 종로 숙소가 위도 37.57, 경도 126.99 부근에 오는지 검증).
3. 야영장은 좌표가 없어 **소재 시군구의 시설 평균 위치로 추정**했습니다. 좌표가 없는 다른 숙소 약 3,500곳은 제외했습니다.
4. 시도명은 17개로 통일했습니다(강원특별자치도→강원도, 전북특별자치도→전라북도, 전남광주통합특별시→광주광역시 또는 전라남도).
5. 숙소마다 반경 3·5·10km 안의 병원·약국·카페식당·여행지 수와 시설 유형 수를 미리 계산해 파일에 넣었습니다.
