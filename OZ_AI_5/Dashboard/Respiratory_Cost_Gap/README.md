# 호흡기 질환 진료비 격차 대시보드

보험료 5분위, 기관 종별, 지역별로 호흡기(J코드) 진료비를 비교하는 단일 HTML 대시보드입니다. 오즈코딩 헬스케어 SQL 3기 실습 데이터(2024–2025 청구 표본)를 사용했습니다.

- `index.html`: 결과물 (호흡기 청구 13,285건 내장)
- `dashboard_template.html`: 화면 코드
- `build_dashboard.py`: 원본 CSV에서 호흡기 청구를 추출해 템플릿에 내장 (원본 CSV는 저장소에 포함하지 않음)

원본 CSV는 같은 폴더에 두고 `python build_dashboard.py`를 실행하면 `청구_대시보드.html`이 만들어집니다.

실습 표본 데이터이므로 전국 통계로 해석할 수 없습니다.
